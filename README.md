# Swiggy Sales Dashboard (Excel)

## 📊 Project Overview
This project is an Excel-based sales dashboard created using Swiggy-style food delivery data.  
The dashboard provides insights into sales performance, customer ratings, order trends, and regional analysis.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning & Analysis

## 📌 Sheets Included
1. **Dashboard** – Interactive visual dashboard with KPIs and trends
2. **Analysis** – Data analysis using pivot tables
3. **Swiggy Dataset** – Raw and cleaned dataset

## 📈 Key Insights
- Total sales, average rating, and order value tracking
- Monthly, weekly, and daily sales trends
- Sales by food category and state
- Top-performing cities by sales
